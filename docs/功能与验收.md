# 功能与验收

## 用户旅程

1. 飞手创建任务并完成采集。
2. 数据管理员导入任务包并查看质量门控。
3. 算法服务完成配准、检测和跨帧聚合。
4. 运维工程师在证据台对照 RGB/Thermal。
5. 人工确认后生成工单，现场处置并上传复测证据。
6. 主管生成报告，研究人员在独立实验空间复现实验。
7. 审计员追踪模型版本、人工操作和状态变化。

## 交互实现边界

- 登录、异常确认和证据建单在持有有效 JWT 时调用 FastAPI；“进入演示环境”会在本地后端可用时建立演示账号会话，后端离线时才降级为纯前端浏览，不伪装成服务端成功。
- 导出按钮生成可下载的 CSV、JSON 或 Markdown 文件；下载内容保留“演示数据/真实实验待运行”边界。
- 任务创建、异常确认和证据建单已接入后端持久化；用户、资产、实验及部分工单界面流转仍属于前端可操作原型，生产部署需补齐相应持久化接口。
- 实时飞行页面只展示接入数据和记录应急事件，不发送悬停、返航、降落等飞控命令。
- 九项质量门控中的航迹、RTK、双模态配对和时间差阈值属于研究原型项目门槛；辐照度与视角引用公开热检查指南，仍不替代现场规程和 IEC 验收。
- “控制链路延迟”表示从厂商地面站读取到的观测指标，不代表本平台拥有飞控指令权限。
- 离线模式冻结远端遥测快照，把人工记录标记为本地缓存，并在恢复连接后进入续传队列；当前原型不声称已实现生产级冲突合并。
- AI 助手不会自动确认异常、派发工单或修改资产状态，关键操作始终由人员触发。
- 证据检测框、热点圆环和标签使用 `1586 × 992` 原始影像坐标系的 SVG 标注层；图片与标注共享同一缩放变换，因此对照滑杆、适应窗口和 75%–200% 缩放不会产生独立漂移。
- 当前热像标注是与演示原图人工核对后的证据坐标，不代表模型已在真实测试集达到相同定位精度；真实算法指标必须由版本化数据集、标注和独立评估生成。
