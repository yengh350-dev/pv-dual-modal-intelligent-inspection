# 安全与部署

## 当前参考实现

- bcrypt 密码哈希
- 短期 JWT 与刷新令牌
- 后端角色权限检查
- 登录和 AI 请求限流
- CORS 白名单
- `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`
- 操作审计日志与请求 ID
- 统一业务错误信封，前端可显示请求追踪号
- 异常/工单状态约束、重复未关闭工单拦截和关闭结论要求
- 系统诊断可报告数据库与业务一致性，但不把平台健康等同于无人机适航
- AI 密钥仅从服务端环境变量读取

## 生产上线前的强制项

1. 删除或强制修改演示账号，使用企业 SSO/OIDC 与 MFA。
2. 将 SQLite 替换为 PostgreSQL，使用迁移工具和独立只读账号。
3. 使用 32 字节以上随机 `JWT_SECRET`；增加刷新令牌轮换、撤销表和设备会话管理。
4. 全站 TLS，配置 CSP、HSTS、反向代理限流和 WAF。
5. 原始影像进入对象存储，开启服务端加密、版本化、生命周期与不可变审计。
6. 上传文件检查扩展名、MIME、文件头、尺寸、解压炸弹、恶意内容和校验和。
7. 租户/场站隔离必须进入数据库查询条件，不只依赖前端筛选。
8. 密钥放入 Secret Manager，不写入仓库、镜像、日志或浏览器。
9. 为备份恢复、告警、日志脱敏、漏洞升级和事故响应建立制度。
10. 飞控网络与业务平台网络隔离。任何控制能力都需要独立安全评审、硬件在环测试和人工授权。

## 数据分级

- L1：公开模型文档与匿名统计
- L2：场站运行指标、一般工单
- L3：原始影像、精确坐标、资产拓扑
- L4：身份凭据、API Key、飞控相关凭据

L3/L4 必须加密、最小权限、访问审计并设置保留期限。
