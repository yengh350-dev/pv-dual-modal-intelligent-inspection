1. 在验证集上比较 416、512、640 分辨率和 416 增强推理，未找到满足整体与热斑不回退门槛的候选。

3. 640 分辨率、冻结前 10 层、8 轮微调：验证 mAP@50-95 为 0.263257，低于统一口径基线 0.272341，未进入测试验收、未启用。
4. 416 分辨率、解冻网络、4 轮低学习率微调：验证 mAP@50-95 从 0.272341 升至 0.282378，热斑 AP@50-95 从 0.192095 升至 0.200785，之后固定候选并做测试集验收。

通过版本使用 AdamW、初始学习率 0.0001、随机种子 20261004、batch 16。
关闭 Mosaic、MixUp、色相与饱和度扰动；保留少量亮度、平移、尺度和水平翻转增强。

## 数据审计

训练 / 验证 / 测试：1148 / 140 / 140 张。检查了图片内容哈希、标签哈希、类别与框边界、帧组重叠。
原图尺寸 640×640；训练集中 2945/3463 个框面积小于 32² 像素，小目标占比约 85%。
这是当前定位精度不足的重要数据特征，但仅提高输入分辨率没有在本次测试中带来改善。

划分使用文件编号连续十帧分组，同组不跨集合、无完全相同文件内容跨集合。
训练/验证、训练/测试、验证/测试分别存在 16、21、4 个一侧具有相邻组的组计数。
文件编号分组并不等于真实独立航次，不能保证时间相关性已消除。
后续真正外部验收需要按场站、航次、相机和组件划分，留出时间间隔，并补充独立采集数据。
当前稀有类别测试样本少，模型评分不可当作已校准的工程故障概率。

## 已落地的算法链路修复

- 热红外和可见光共用原图坐标序列化。先裁剪到原图，再由同一未取整坐标生成像素框与归一化框。
- 丢弃非有限坐标、倒置/零面积框、非法类别与分数，返回 `rejectedDetections`，避免错误框进入显示和派单。
- 分割多边形检查有限值、边界和有效面积，丢弃无效轮廓。
- 上传图像校验真实编码和像素数。JPEG/PNG 显式解码，避免 Ultralytics 修改 Image.open 后对坏图触发 HEIF 依赖安装。
- 视频帧在缩放与推理之前处理 EXIF 旋转，保存的证据图与推理坐标使用同一方向。
- 修复功率 API 字段映射，补上真实 API 调用测试；时间周期特征使用与训练 `dt.hour` 一致的整点编码。
- 功率输入或模型输出为 NaN/Infinity 时拒绝处理，不再静默转成零功率。
- 波形检查数值、缺失值、严格递增时间和采样连续性。特征超出 float32 数值范围时拒绝处理，而非将溢出值送进分类器。
- 波形结果同时返回每个 512 点窗口的工况、分数、样本索引和时间范围，保留原整段主导类别接口，并返回被舍弃的末尾样本数量。
- 分割推理移入线程池，避免 CPU 推理阻塞异步接口事件循环。

波形连续性检查使用相邻时间步相对中位步长的 0.5 到 1.5 范围，是输入有效性保护规则，不是经过现场标定的采样率适配算法。
未自动重采样、填补 NaN、插值制造测量值，也未将仿真类别直接变成现场故障结论。
现有辐射测温标定、配准质量与人工复核门控保留。

## 启用与回退

平台启动时读取 `backend/models/active_thermal.json`。
只有登记过的热红外模型、通过验证的评估记录、模型卡与权重哈希一致时，才启用 v2。
配置缺失使用 v1；配置损坏、未知版本、验证记录缺失或哈希不匹配会回退 v1，并在模型清单中返回 `activationWarning`。
已运行的后端需重启，才能载入新权重；研究页面当前指标来自模型清单，不再用旧数值冒充当前结果。
旧训练图、混淆矩阵与样例明确标记为 v1 历史证据。
