# RGB-Thermal 光伏巡检工业指标与判读边界

本文解释平台中关键技术字段“测量什么、影响什么、不能证明什么”。界面中的数值是可交互演示数据，真实项目必须由设备标定、任务清单和现场记录提供。

## 1. 采集与定位

| 指标 | 大白话解释 | 主要作用 | 不能单独证明 |
|---|---|---|---|
| GSD（cm/px） | 地面上多大的区域落到一个像素里 | 判断组件细节是否足够清楚，规划飞行高度 | 不等于缺陷定位精度，也不保证图像清晰 |
| 航向/旁向重叠率 | 前后照片、相邻航带重复拍到多少 | 支持拼接、跨帧复核和漏检控制 | 重叠率高不代表没有运动模糊或曝光问题 |
| RTK 固定解 | 无人机收到差分改正后的高精度定位状态 | 帮助航迹回放、组件级回挂和复飞定位 | 接收机报告的厘米级精度不等于最终缺陷坐标误差 |
| 姿态与相机外参 | 无人机朝向以及相机相对机身的安装关系 | 把图像像素投到地图和组件位置 | 参数过期会造成系统性偏移，不能靠 RTK 自动补偿 |
| RGB-T 时间差 | 一对可见光和热像相隔多久拍摄 | 降低飞行移动造成的错位 | 时间相近仍需空间配准 |

## 2. 热成像与配准

| 指标 | 大白话解释 | 主要作用 | 判读边界 |
|---|---|---|---|
| NETD（mK） | 传感器分辨微小温差的能力，越小通常越敏感 | 评估热纹理和小温差可见性 | 它不是绝对测温精度 |
| 发射率 ε | 物体把热辐射发出来的能力参数 | 影响辐射测温换算 | 必须结合组件材料、角度和设备说明校准，不能固定套用演示值 |
| 反射温度/环境温度 | 周围物体和天空反射进镜头的热背景 | 排查太阳反射、天空反射等伪热斑 | 环境温度不等于组件背板或电池片真实温度 |
| ΔT | 目标区域与参考区域的相对温差 | 在同一任务内排序风险，减少绝对温度偏差影响 | 阈值必须和场站规程、辐照度、风速、负载共同确定 |
| 配准误差（px） | RGB 与热像中的同一位置平均错开多少像素 | 判断热异常能否可靠落到可见光组件上 | 中位数会隐藏局部大误差，应同时看分位数和失败帧 |

## 3. 模型与证据

- **模型置信度**是模型对类别的相对把握，不是“真实故障概率”。不同版本、数据分布和校准方法下不能直接横向比较。
- **跨帧持续性**用于判断热异常是否在连续画面稳定出现。单帧高温可能来自反射、遮挡、运动模糊或配准失败。
- **质量门控**应先检查模态齐全、时间同步、清晰度、过曝、热像标定和配准，再允许模型结果进入人工复核。
- **人工结论**必须保留操作者、时间、模型版本、原始证据引用、状态变化和请求追踪号。
- **现场确认**可包含电压/电流、旁路二极管、连接器、表面污染和复测热像。平台影像不能替代全部电气检测。

## 4. 无人机连接边界

平台把无人机接入分成三层：

1. 厂商地面站负责飞控、返航、禁飞区、遥控链路和适航确认。
2. 适配器读取任务、遥测、RGB/Thermal 文件及元数据，并转换成平台清单。
3. Sentinel RGBT 负责证据接收、质量检查、复核、工单、报告和审计。

“在线”只表示近期收到心跳或数据，不代表飞行器可安全起飞。任何未来的控制能力都应独立隔离、授权和验证，不能直接复用证据平台接口。

## 5. 生产数据最低要求

- 每帧包含唯一文件路径、`pairId`、模态、带时区时间戳、经纬度和高度基准。
- 每个 `pairId` 恰好包含一张 RGB 和一张 Thermal，重复模态必须阻断。
- 保存原始文件校验和、设备序列号、固件、镜头/载荷、标定版本和任务时区。
- 原始数据只读保存；派生图、模型框、温度统计和人工结论分层存储。
- 训练、验证、测试按场站或任务划分，避免相邻帧泄漏造成虚高结果。
- 报告明确区分“模型提示”“人工确认”和“现场电气确认”。

## 6. 飞行与证据质量门控

平台新增任务级质量门控，用来回答“无人机有没有按计划飞、影像能不能可靠回挂、这批热像是否具备分析条件”。门控先于 AI 分析执行，阻断项失败时不得把模型结果直接送入自动处置。

| 检查项 | 演示项目门槛 | 计算与用途 | 边界 |
|---|---:|---|---|
| P95 横向航迹偏差 | ≤ 0.5 m | 实际轨迹采样点到计划航线最近点距离的 95 分位数 | 项目内部门槛，不是厂商定位保证 |
| 最大横向航迹偏差 | ≤ 1.5 m | 暴露转弯、避障或局部链路波动造成的大偏离 | 不能用平均误差替代 |
| RTK FIX 有效率 | ≥ 95% | 有效遥测采样中固定解的占比 | 厂商厘米级 RTK 规格不等于缺陷坐标误差 |
| AGL 高度 P95 波动 | ≤ 2.0 m | 检查地形跟随、目标尺度和 GSD 稳定性 | 山地任务应结合 DEM、测距和飞控日志 |
| 影像回挂 P95 残差 | ≤ 0.5 m | 综合时间戳、姿态和相机外参后的组件级定位残差 | 必须基于控制点或可验证组件位置评估 |
| RGB-Thermal 配对率 | ≥ 97% | `pairId` 同时具备 RGB 与 Thermal 的比例 | 缺失对必须隔离，不能静默补齐 |
| 双模态时间差 P95 | ≤ 100 ms | 同一证据对采集时间差的 95 分位数 | 通过后仍需做空间配准 |
| 太阳辐照度 | ≥ 600 W/m² | 保证光伏组件具有足够热对比 | 来自 FLIR 公开检查指南；现场仍按项目规程执行 |
| 最小观测夹角 | ≥ 30° | 降低低角度反射和太阳眩光干扰 | 应由云台姿态、组件倾角与航迹联合计算 |

质量分只表示上述检查项的通过比例，不表示“飞行安全分”或“故障真实性概率”。质量门控记录应包含任务编号、采样数、计算时间、阈值版本、失败原因、设备与固件信息，并可导出供审计和复飞使用。

## 7. 设备与方法依据

- DJI Mavic 3T 官方规格：热像 `640×512 @ 30 Hz`、NETD `≤50 mK @ F1.0`，高增益测温精度为 `±2°C` 或 `±2%`（取较大者）；RTK FIX 水平精度为 `1 cm + 1 ppm`。<https://enterprise.dji.com/mavic-3-enterprise/specs>
- DJI Matrice 350 RTK 官方规格：RTK FIX 水平 `1 cm + 1 ppm`、垂直 `1.5 cm + 1 ppm`，最大抗风速 `12 m/s`，最长飞行时间为无载荷无风实验条件下 `55 min`。<https://enterprise.dji.com/matrice-350-rtk/specs>
- DJI Zenmuse H20T 官方规格：辐射热像 `640×512 @ 30 Hz`、R-JPEG 16 bit、NETD `≤50 mK @ F1.0`、光谱范围 `8–14 μm`。<https://enterprise.dji.com/zenmuse-h20-series/specs>
- Autel EVO Max 4T 官方规格：热像 `640×512 @ 30 fps`、`25 mm` 镜头、NETD `≤50 mK`，高增益范围 `-20°C 至 150°C`，测温精度 `±3°C` 或读数 `±3%`（取较大者）。<https://www.autelrobotics.com/productdetail/EVO-Max-4T/>
- IEC TS 62446-3:2017 定义运行中光伏组件和场站的户外红外热成像检查，并覆盖设备、环境、过程、报告和人员资格。<https://webstore.iec.ch/en/publication/28628>
- FLIR 光伏无人机热检查公开指南提出至少 `600 W/m²` 的辐照度基线，并提醒观测角度、发射率、反射温度、空气温湿度和距离都会影响测温。<https://inteindustrial.flir.com/suas/delta/delta-solutions-series-part-4-Thermal-Inspection-of-Solar-Panels/>

以上资料用于建立界面中的能力基线和判读边界。真实部署必须重新核对具体型号、序列号、固件、镜头、标定证书、地区法规和场站作业规程。
