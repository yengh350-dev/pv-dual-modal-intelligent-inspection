# 证据质量门控与决策边界

## 1. 目的

平台把“模型发现疑似异常”与“工程故障结论”明确分开。模型输出只用于排序和辅助复核；维修、停机、换件等结论必须由具备权限的人员结合现场电气测量确认。

当前规则版本为 `evidence-gate-2.0.0`，实现位于 `backend/app/decision_engine.py`，接口为 `POST /api/v1/analysis/evaluate`。

## 2. 输入与含义

| 输入 | 含义 | 当前门槛 |
| --- | --- | --- |
| `alignmentQuality` | RGB 与 Thermal 对齐质量，范围 0-1 | 小于 0.85 阻断 |
| `registrationErrorPx` | 特征重投影误差 | 大于 5 px 阻断 |
| `syncOffsetMs` | 双模态时间偏差 | 大于 250 ms 阻断 |
| `localizationAccuracyM` | 事件定位误差 | 大于 3 m 警告 |
| `persistentFrames` | 异常连续出现帧数 | 少于 2 帧阻断 |
| `persistentSeconds` | 异常持续时间 | 少于 1 s 警告 |
| `radiometricCalibrated` | 热像是否保留辐射测温标定 | 否则阻断 |
| `environmentComplete` | 环温、辐照度等环境信息是否完整 | 不完整则警告 |
| `temperatureDeltaC` | 组件相对环境或邻近组件温差 | 仅参与复核优先级 |
| `modelConfidence` | 缺陷候选模型置信度 | 仅参与复核优先级 |
| `irradianceWM2` | 现场辐照度，可选 | 低于 300 W/m² 阻断，300–600 W/m² 警告 |
| `temperatureUncertaintyC` | 测温综合不确定度 | 扩展温差区间并降低紧迫度 |
| `reflectionRisk` | 反射干扰风险，范围 0-1 | 降低可靠度，达到 0.35 时警告 |
| `occlusionRatio` | 目标遮挡比例，范围 0-1 | 达到 0.60 时阻断 |
| `repeatObservations` | 跨任务重复观测次数 | 只参与复核排序 |
| `assetCriticality` | 资产运行影响，范围 0-1 | 只参与复核排序 |

## 3. 质量分与门控

原始质量分由对齐、配准、同步、定位、跨帧持续、测温标定和环境信息七部分加权形成。可靠度在原始质量分基础上扣除反射与遮挡惩罚。两种分数均用于解释证据可用性，不等同于缺陷概率。

- `blocked`：存在硬阻断项，不能进入工程判读。
- `review`：证据可查看，但存在警告或质量分不足 85。
- `pass`：证据链完整，可进入人工复核。

硬阻断优先于总分。即使总分较高，只要缺少辐射测温标定、对齐严重失败或异常只在单帧出现，也必须阻断。

## 4. 复核优先级

优先级只决定“先看哪一条”，不决定“是什么故障”。复核紧迫度综合温差、模型支持、跨帧持续、重复观测、资产影响与证据可靠度，并扣除测温不确定度、反射和遮挡影响：

- `critical_review`：高温差、高置信度且跨帧稳定，优先复核。
- `high_review`：较高温差或较高置信度，当班复核。
- `medium_review`：证据可用但紧迫度一般，常规复核。
- `observe`：暂时观察并积累更多证据。
- `unrated`：存在阻断项，暂不分级。

## 5. 回退与审计

前端在接口不可达时会显示“本地回退”，只保持影像和元数据可浏览。离线状态固定为阻断，不计算复核优先级，也不允许确认异常或创建工单，避免用前端简化逻辑冒充服务端结论。正式部署应把请求输入、规则版本、输出、人工操作和时间戳写入审计日志，并定期用独立验证集检查阈值漂移。

接口同时返回 `actionEligibility`。存在硬阻断时禁止确认和创建工单；满足证据门控后仍须先由人工把异常状态改为“已确认”，后端才允许创建处置工单。

## 6. 任务级门控

`GET /api/v1/missions/{id}/quality-gate` 还会对任务批次计算航迹跟踪、RTK 可用率、高度稳定、地理标记精度、双模态配对完整率、时间同步和观测角七项分数。任务级硬阻断优先于单帧模型结果；批次被阻断时，其帧不得直接进入缺陷分析。

## 7. 后续校准

当前阈值是原型阶段的保守默认值。接入真实无人机和场站后，应按相机参数、飞行高度、辐照条件、组件类型和现场复测结果分层标定，并通过版本化规则或配置中心发布，禁止直接在生产代码中无记录地修改阈值。
